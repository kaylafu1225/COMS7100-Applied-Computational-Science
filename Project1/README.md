# Project 1 — Nonlinear Least-Squares Equation of State Fitting

## Overview

This program fits experimental pressure-volume data to a specified equation of state (EOS) using nonlinear least-squares optimization.

The program automatically reads the EOS model, temperature, units, initial parameters, and experimental data from the input file. The user can then select an optimization method.

### Supported Equations of State

* van der Waals (`vdw`)
* Redlich-Kwong (`rk`)
* Dieterici (`dieterici`)
* Berthelot (`berthelot`)

### Optimization Methods

* Gradient Descent (`GD`)
* Gauss-Newton (`GN`)
* Levenberg-Marquardt (`LM`)
* All three methods (`ALL`)

## Running the Program

Open a terminal in the project directory and run:

```bash
python3 P1.py
```

The program will display the available data files and ask the user to select one.

It will then display the optimization menu:

```text
[1] Gradient Descent
[2] Gauss-Newton
[3] Levenberg-Marquardt
[4] Run all methods and compare
```

Enter the number corresponding to the desired method.

## Input File

The input file contains the information required for EOS fitting, including:

* Equation of state
* Temperature
* Units
* Initial parameter values
* Experimental molar volume
* Experimental pressure

The EOS keyword is case-insensitive.

Supported EOS keywords include:

```text
vdw
rk
dieterici
berthelot
```

The program converts the input data to SI units before performing the fitting procedure.

---

## Optimization

The program minimizes the sum of squared residuals:

```text
SSE = Σ(P_experimental - P_calculated)^2
```

where the calculated pressure is obtained from the selected equation of state.

Three nonlinear optimization methods are available.

### Gradient Descent (GD)

Gradient Descent updates the EOS parameters in the direction of decreasing SSE.

### Gauss-Newton (GN)

Gauss-Newton uses the Jacobian matrix of the residuals to estimate parameter updates.

### Levenberg-Marquardt (LM)

Levenberg-Marquardt combines characteristics of Gradient Descent and Gauss-Newton through a damping parameter.

If `ALL` is selected, all three methods are executed and their fitting results are compared.

---

## Statistical Analysis

After optimization, the program calculates fitting statistics including:

* Optimized parameters `a` and `b`
* Sum of Squared Errors (SSE)
* Root Mean Squared Error (RMSE)
* R-squared
* Adjusted R-squared
* R-factor
* Standard errors of optimized parameters
* Sample variance
* Covariance matrix
* Correlation coefficients
* Chi-square
* Number of iterations
* Convergence status

## Output

The program automatically creates a folder inside `result`.

The folder name follows the format:

```text
filename_EOS_method
```

For example, if the input file is `data1.txt`, the EOS is `vdw`, and Levenberg-Marquardt is selected:

```text
result/
└── data1_vdw_LM/
    ├── data1_vdw_LM_results.csv
    ├── data1_vdw_LM_fit.png
    └── data1_vdw_LM_residuals.png
```

The three output files contain:

### Results CSV

```text
data1_vdw_LM_results.csv
```

Contains the optimized parameters and statistical fitting results.

### Fitted EOS Plot

```text
data1_vdw_LM_fit.png
```

Shows the experimental pressure-volume data together with the fitted EOS curve.

### Residual Plot

```text
data1_vdw_LM_residuals.png
```

Shows the residual pressure as a function of molar volume.

---

## Running All Methods

If `ALL` is selected, the program runs GD, GN, and LM and displays an optimization method comparison.

The results are stored in:

```text
result/
└── data1_vdw_ALL/
```

The comparison can be used to determine which optimization method gives the lowest SSE among the converged methods.

When only one optimization method is selected, the method comparison is not displayed.

---

## Notes

* Make sure the input data file follows the required format.
* Initial parameter values should be physically reasonable.
* The optimization is considered successful only when the selected method satisfies its convergence criteria.
* Poor initial parameters may result in slow convergence or failure to converge.
* Output files are automatically organized by input filename, EOS model, and optimization method.
